# xeokit-bim-viewer source information

CampusTwin vendors the official `xeokit/xeokit-bim-viewer` application and its
unmodified Archicad demonstration XKT assets from commit
`a86a91a399d4725d77df34ad715f986534d08952` (version 2.7.1).

Upstream source: https://github.com/xeokit/xeokit-bim-viewer

The viewer entry page is adapted only to apply CampusTwin state through a
same-origin `postMessage` bridge and to load the bundled demonstration project.
The complete upstream corresponding source is available at the commit above.
