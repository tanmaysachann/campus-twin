# Security and governance notes

## Authentication model

In Databricks Apps, CampusTwin expects user authorization and reads the platform-forwarded access token per request. Local development may use `DATABRICKS_TOKEN`, but the example file labels this as development-only.

No token is sent to the browser by CampusTwin. All SQL and Genie API calls originate from the FastAPI server.

## Least privilege

The bundle requests only user API scopes required by the vertical slice:

```yaml
user_api_scopes:
  - sql
  - genie
```

The SQL warehouse is bound as an app resource with `CAN_USE`. Unity Catalog permissions still govern the user's reachable data.

## Cross-user cache isolation

A global cache of governed rows could leak one user's data visibility to another user. CampusTwin therefore keys cached snapshots by the request identity and data source.

## Data minimization

The bundled dataset contains aggregate sections and operational assets, not personally identifying student records.

## Bootstrap safeguards

- infrastructure mutation is explicit;
- force reseed is opt-in and visibly destructive;
- normal bootstrap seeds only empty canonical tables;
- schema/table creation is idempotent;
- `CAMPUS_TWIN_ALLOW_BOOTSTRAP=false` can disable the endpoint.

For a production deployment, additionally put admin authorization around `/api/admin/bootstrap`; the competition vertical slice relies on workspace app access plus database permissions.

## SQL injection boundary

Runtime data reads use fixed statements. Scenario inputs do not become SQL. Feedback/scenario persistence uses named Statement Execution parameters.

Bootstrap identifiers come from administrator-controlled application configuration (`catalog`/`schema`), not request payloads. Seed values are generated by the repository and escaped before bulk insert.

## Model honesty

The security boundary includes epistemic safety:

- simulated coefficients are labeled as assumptions;
- local analysis is never called Genie;
- scheduled room utilization is never called live occupancy;
- the scenario clone cannot mutate the baseline snapshot;
- uncertainty bands are not called empirical confidence intervals.
